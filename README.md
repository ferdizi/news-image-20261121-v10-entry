A deterministic Node 22 program that draws a 1024×1024 newspaper front page summing up Saturday 21 November 2026: 36 dated stories across 7 regions, a UTC timeline, a dotted world map with numbered pins, and a DATE CHECK box listing what was left out. Glyphs are real Liberation font outlines extracted with fontTools and embedded as text; no network, clock or randomness — two runs produce a byte-identical PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
